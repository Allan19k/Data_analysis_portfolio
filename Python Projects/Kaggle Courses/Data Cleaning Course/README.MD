# 🧽 Data Cleaning – Kaggle Learn

Este repositorio documenta los ejercicios realizados durante el curso **"Data Cleaning"** de [Kaggle Learn](https://www.kaggle.com/learn/data-cleaning), enfocado en técnicas fundamentales para limpiar, preparar y transformar datos antes del análisis.

---

## 🎯 Objetivo

Adquirir las habilidades necesarias para identificar y corregir errores comunes en conjuntos de datos reales, facilitando el análisis, modelado y visualización confiables.

---

## 📚 Contenido del curso

El curso está compuesto por 5 lecciones, cada una acompañada de ejercicios prácticos en notebooks:

| Módulo                        | Descripción                                                                 |
|------------------------------|-----------------------------------------------------------------------------|
| `1. Handling_missing_values.ipynb` | Eliminar o imputar valores nulos con flujos de trabajo automatizados        |
| `2. Scaling_and_normalization.ipynb` | Transformar variables numéricas para mejorar su distribución o comparabilidad |
| `3. Parsing-Dates.ipynb`           | Reconocer y convertir columnas con fechas a formatos de tipo datetime       |
| `4. Character_encodings.ipynb`     | Identificar y corregir errores de codificación de texto (unicode) al cargar archivos |
| `5. Inconsistent_data_entry.ipynb` | Detectar y corregir errores tipográficos o inconsistencias en valores categóricos |

---

## 🧠 Habilidades desarrolladas

- Detección y tratamiento de valores nulos (`dropna()`, `fillna()`)
- Estandarización de columnas numéricas (`StandardScaler`, `minmax`)
- Manipulación de fechas y conversión de tipos
- Resolución de errores de codificación (`utf-8`, `ISO-8859-1`, etc.)
- Agrupación y corrección de registros inconsistentes (`replace()`, `map()`)


---

## 📌 Aplicación práctica

Estas técnicas son utilizadas antes de cualquier análisis o modelado para garantizar resultados válidos y reproducibles. Este módulo es esencial para tareas como regresión, clasificación, visualización o carga de datos a bases estructuradas.

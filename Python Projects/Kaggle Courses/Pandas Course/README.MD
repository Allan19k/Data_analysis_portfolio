# 🐼 Curso de Pandas – Kaggle Learn

Este repositorio documenta los ejercicios completados durante el curso **"Pandas"** de [Kaggle Learn](https://www.kaggle.com/learn/pandas), orientado al análisis y manipulación de datos en Python con la biblioteca `pandas`.

---

## 🎯 Objetivo

Desarrollar habilidades fundamentales para leer, transformar, agrupar, limpiar y combinar datos usando `pandas`, una de las librerías más utilizadas en ciencia de datos.

---

## 📚 Contenido del curso

El curso se divide en 6 lecciones prácticas, cada una acompañada de ejercicios interactivos ejecutados en notebooks:

| Módulo                          | Descripción                                                                 |
|--------------------------------|-----------------------------------------------------------------------------|
| `1. Creating, Reading and Writing`           | Crear `Series` y `DataFrames`, leer archivos `.csv` y guardar resultados con `to_csv()` |
| `2. Indexing, Selecting & Assigning`         | Uso de `.loc`, `.iloc`, filtrado condicional (`==`, `&`, `|`)              |
| `3. Summary Functions and Maps`              | Estadísticas básicas, funciones de resumen, `map()` y `apply()`            |
| `4. Grouping and Sorting`                    | Agrupación (`groupby()`), `multi-index`, ordenamiento por columnas         |
| `5. Data Types and Missing Values`           | Tipos de datos (`dtypes`), manejo de valores nulos (`isna()`, `fillna()`)  |
| `6. Renaming and Combining`                  | Renombrar columnas y combinar datasets con `concat()`, `join ()`           |

En todos los ejercicios se trabajo con la siguiente base de datos de Kaggle ("Wine Reviews") [https://www.kaggle.com/datasets/zynicide/wine-reviews]
Aunque, en el último ejercicio "Renaming and Combing" se trabajo además con otras 2 bases de datos también de Kaggle:
- [Things on Redit] (https://www.kaggle.com/datasets/residentmario/things-on-reddit/data)
- [Powerlifting Database] (https://www.kaggle.com/datasets/open-powerlifting/powerlifting-database)

---

## 🧠 Habilidades desarrolladas

- Limpieza y exploración de datos
- Operaciones sobre columnas y filas

- Manejo de datos faltantes

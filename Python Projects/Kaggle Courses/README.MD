# 🧪💡  Kaggle Courses – Python Projects

Esta carpeta forma parte de mi portafolio de análisis de datos y contiene los ejercicios y proyectos que realicé como parte de los cursos ofrecidos por **Kaggle Learn**. Los cursos aquí incluidos están enfocados en reforzar mis habilidades en el uso de **Python** para el análisis y procesamiento de datos, cubriendo desde los fundamentos del lenguaje hasta técnicas avanzadas de visualización y limpieza de datos.

---

## 📘 Cursos Completados

### 1. `Python` 🐍
Fundamentos esenciales del lenguaje Python, incluyendo:
- Sintaxis básica, tipos de datos y operadores.
- Uso de funciones y documentación integrada.
- Estructuras como listas, diccionarios y bucles.
- Comprensiones de listas y trabajo con librerías externas.

---

### 2. `Pandas` 🐼
Manipulación de datos con la poderosa librería `pandas`:
- Creación y lectura de `Series` y `DataFrames`.
- Indexación, filtrado y asignación de valores.
- Funciones resumen, agrupamiento y ordenamiento.
- Manejo de valores faltantes, combinación de datasets y renombramiento de columnas.

---

### 3. `Data Cleaning` 🧼
Limpieza y preparación de datos reales para su análisis:
- Manejo de valores faltantes con `dropna()` y `fillna()`.
- Escalado y normalización de variables numéricas.
- Análisis de fechas y formatos inconsistentes.
- Corrección de errores de codificación y entradas inconsistentes.


---

### 4. `Data Visualization` 📊
Visualización de datos con `Seaborn` y `Matplotlib` :
- Gráficos de líneas, barras, mapas de calor y dispersión.
- Visualización de distribuciones (histogramas y gráficos de densidad).
- Selección de tipos de gráficos adecuados y personalización del estilo.
- Proyecto final usando un dataset real del vino para explorar relaciones entre variables.

---

## 🎯 Objetivo de esta Carpeta

Este espacio busca demostrar de forma práctica mis conocimientos en el uso de Python aplicado al análisis de datos. Todos los ejercicios se centran en:
- Adquirir experiencia con librerías clave del ecosistema de datos.
- Aplicar buenas prácticas en la limpieza, manipulación y visualización de datasets.
- Prepararme para entornos de trabajo reales en el área de análisis de datos.

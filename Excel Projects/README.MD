# 📊 Excel Projects

Esta sección contiene ejercicios, prácticas y aplicaciones reales en **Microsoft Excel**, una herramienta clave en análisis de datos. El propósito de esta carpeta es mostrar dominio progresivo de Excel, desde funciones básicas hasta aplicaciones más avanzadas como **Solver**, **tablas dinámicas**, y en el futuro, **dashboards profesionales**, **macros** y **VBA**.

---

## 🧱 Estructura de la Carpeta

- [`Fundamentos_de_Excel/`](./Fundamentos_de_Excel):  
  Curso tomado a través de **Santander Open Academy**, el cual abarca desde nivel básico hasta intermedio. Incluye temas como:
  - Rango vs Tabla
  - Filtrado y segmentación
  - Funciones: `SI`, `BUSCARV`, `CONTAR`, `CONTAR.SI`, etc.
  - Tablas dinámicas y organización de datos

- [`Solver/`](./Solver):  
  Ejercicio práctico de **Investigación de Operaciones** utilizando la herramienta **Solver** de Excel para **optimización lineal**.  
  Se resolvió un problema de maximización de ganancias bajo restricciones de recursos.

Este repositorio busca demostrar habilidades técnicas aplicadas en Excel, no solo desde un enfoque académico, sino también con **casos prácticos**, útiles para la industria y en especial, para una futura carrera profesional en el área de **Data Analysis o Data Engineering**.

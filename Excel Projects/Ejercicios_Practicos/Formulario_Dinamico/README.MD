# 📋 Formulario dinámico para ingreso rápido de datos en Excel

## 📌 Objetivo
Facilitar y agilizar el registro de datos en una tabla de Excel mediante el uso de la herramienta **Formulario**, evitando desplazarse manualmente por las columnas.

## 📝 Descripción
En este ejercicio se configuró un formulario dinámico que permite:
- Seleccionar una tabla de Excel con campos predefinidos.
- Abrir un formulario emergente que muestra automáticamente los campos de la tabla (Ejemplo: `Empleado`, `Código`, `Área` y `Sueldo`).
- Agregar registros nuevos con el botón **Nuevo** de forma instantánea.
- Navegar entre registros existentes para editar o eliminar información.

Este método es ideal para bases de datos pequeñas o medianas donde la velocidad y facilidad de entrada de datos es importante.

## ⚙️ Funciones y herramientas utilizadas
- **Creación de tabla estructurada en Excel** para definir campos y registros.
- **Herramienta Formulario** (activada desde la barra de acceso rápido).
- **Funciones de navegación y creación de registros** integradas en la herramienta.

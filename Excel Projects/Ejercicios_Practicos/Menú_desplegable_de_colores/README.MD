# 🎨 Menú desplegable de colores con formato condicional

## 📌 Objetivo
Crear un menú desplegable en Excel que permita seleccionar un estado ("Aprobado" o "Desaprobado") y resaltar automáticamente toda la fila con colores personalizados, mejorando la visualización y el control de registros.

## 📝 Descripción
Este ejercicio demuestra cómo aplicar un **menú desplegable** con opciones específicas y cómo vincularlo con **formato condicional** para resaltar dinámicamente información relevante en una tabla de datos.  
Cada fila cambia de color automáticamente dependiendo del estado de la compra, facilitando la interpretación visual y el análisis rápido de los datos.

## ⚙️ Funciones y herramientas utilizadas

- **Validación de datos (Data Validation)**  
  Se creó un menú desplegable con opciones: `Aprobado` y `Desaprobado`.

- **Formato condicional (Conditional Formatting)**  
  Se aplicaron reglas para cambiar el color de fondo y texto de cada fila con base en la opción seleccionada:
  - Verde para "Aprobado"
  - Rojo para "Desaprobado"

- **Diseño personalizado**  
  Se aplicó un título destacado y estructura organizada para simular un entorno más profesional de control de estados.

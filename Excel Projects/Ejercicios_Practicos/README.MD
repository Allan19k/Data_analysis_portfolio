# 🧩 Ejercicios_Practicos

Esta sección forma parte del portafolio de análisis de datos, y tiene como objetivo documentar ejercicios prácticos y estrategias desarrolladas en **Microsoft Excel**, enfocados en **automatizar tareas**, **optimizar procesos** y **resolver problemas reales** aplicados al entorno empresarial o académico.

## 🎯 Objetivo

Demostrar el uso de Excel más allá de lo básico, aplicando funciones, herramientas y metodologías que permitan:

- Analizar datos de manera eficiente.
- Agilizar procesos repetitivos.
- Automatizar operaciones y simulaciones.
- Resolver escenarios reales mediante técnicas de optimización y validación.

## ⚙️ Herramientas y funciones aplicadas

Algunos de los elementos usados (según el ejercicio) incluyen:

- **Funciones Lógicas**: `SI`, `Y`, `O`, `SI.ERROR`
- **Funciones de Búsqueda**: `BUSCARV`, `BUSCARX`, `ÍNDICE`, `COINCIDIR`
- **Tablas y Rangos**: creación, conversión, segmentación y formato
- **Validación de Datos**
- **Tablas Dinámicas**
- **Referencias Relativas y Absolutas**
- **Solver** (optimización)
- **Gráficos y visualizaciones básicas**
- **Uso de complementos y herramientas adicionales**
- **Macros y VBA** (por incluir en ejercicios futuros)
- **y mucho mas...**

## 📁 Estructura

Cada ejercicio tiene su propia carpeta o con:

- El archivo Excel correspondiente (`.xlsx` o `.xlsm`)
- Un `README.md` que explica:
  - Objetivo
  - Descripción 
  - Funciones y herramientas utilizadas

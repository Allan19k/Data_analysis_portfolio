# Consultas SQL – Oracle Database

Esta sección del portafolio reúne y documenta los ejercicios prácticos realizados en **SQL utilizando Oracle Database**, enfocados en el dominio de consultas, manipulación y análisis de datos.  
El objetivo principal es reforzar la lógica de consulta, el manejo de datos relacionales y las bases necesarias para análisis de datos y sistemas de información.

Cada subsección aborda un conjunto específico de conceptos clave de SQL, desde operaciones básicas hasta consultas más avanzadas.

---

## 📌 Contenido de la sección

### 🔹 DML (Data Manipulation Language)
Ejercicios enfocados en la manipulación de datos dentro de las tablas:
  - `INSERT` para agregar registros  
  - `UPDATE` para modificar información existente  
  - `DELETE` para eliminar registros  
  - Buenas prácticas en el manejo de datos

---

### 🔹 Proyección y Selección
Consultas básicas para la obtención de información:
  - Uso de `SELECT`
  - Filtrado con `WHERE`
  - Uso de operadores lógicos y relacionales
  - Selección de columnas específicas para análisis

---

### 🔹 Agrupamientos
Análisis de datos mediante funciones de agregación:
  - Uso de `GROUP BY`
  - Funciones como `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`
  - Filtrado de grupos con `HAVING`
  - Casos prácticos de análisis resumido de datos

---

### 🔹 Joins
Consultas que combinan información de múltiples tablas:
  - `INNER JOIN`
  - `LEFT JOIN`
  - `RIGHT JOIN`
  - Comprensión de relaciones entre tablas
  - Resolución de consultas relacionales reales

---

### 🔹 Subconsultas
Consultas anidadas para resolver problemas más complejos:
  - Subconsultas en `SELECT`, `WHERE` y `FROM`
  - Uso de operadores como `IN`, `EXISTS`, `ANY`, `ALL`
  - Comparación entre subconsultas y joins

---

### 🔹 Vistas (Views)
Creación y uso de vistas para simplificar consultas:
  - `CREATE VIEW`
  - Consultas sobre vistas
  - Ventajas de las vistas en seguridad y reutilización
  - Abstracción de lógica compleja

---

## 🧠 Objetivos
- Fortalecer la lógica de consultas SQL
- Comprender el manejo de bases de datos relacionales
- Preparar bases sólidas para análisis de datos, reporting y herramientas como Power BI
- Aplicar SQL en contextos académicos y profesionales

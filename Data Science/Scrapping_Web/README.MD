# 🕵️‍♂️ Web Scraping con Python – Herramientas Open Source para Data Science  

Este proyecto surge a partir de un tutorial de YouTube sobre **Web Scraping en Python**, https://youtu.be/Ew44dS0mw-E?si=GbRhjFCaYaq9xMzS , al cual se le añadió una extensión para analizar cuáles son las **herramientas Open Source más mencionadas en el campo del Data Science**, agrupadas en diferentes categorías.  

---

## ⚙️ Tecnologías utilizadas
- **Python 3**  
- **Librerías principales**:  
  - `requests` → para realizar peticiones HTTP y obtener el contenido HTML.  
  - `BeautifulSoup` → para parsear y extraer datos del HTML.  
  - `matplotlib` → para generar visualizaciones.  

---

## 📊 Flujo del proyecto
1. **Extracción de datos:**  
   Se realizó scraping de comentarios para identificar menciones a herramientas de Data Science.  

2. **Clasificación de herramientas:**  
   Se agruparon en las siguientes categorías:  
   - 📂 **Data Management**  
   - 🔗 **Data Integration and transformation**  
   - 📉 **Data Visualization**  
   - 🧩 **Model Building** 
   - 🤖 **Model Deployment**  
   - 🎲 **Model Monitoring and Assesment** 
   - 🚀 **Code Assets Management** 
   - 🔭 **Data assets management**
   - 🔍 **Developed Environments**
   - 👀 **Execution Environments**

3. **Análisis de frecuencia:**  
   Se contabilizó cuántas veces se mencionaba cada herramienta.  

4. **Visualización:**  
   Se construyeron gráficas para mostrar de manera clara cuáles son las herramientas más populares.  

---

## 📂 Estructura del proyecto
- `Scrapping_Web.ipynb` → Notebook con todo el código documentado.  
- `Herramientas_DS.pdf` → Documento base con listado de herramientas Open Source.  
- `graficos/` → Carpeta con imágenes de las visualizaciones generadas.  

---

## 🎯 Aprendizaje
Este proyecto permitió:  
- Poner en práctica conceptos de **web scraping** con Python.  
- Identificar tendencias en el uso de herramientas de Data Science.  
- Practicar **visualización de datos** para comunicar resultados de manera efectiva.
